# KrasView TV

[![Build and test](https://github.com/Krarotus/krasview-tv/actions/workflows/build.yml/badge.svg)](https://github.com/Krarotus/krasview-tv/actions/workflows/build.yml)

Нативный клиент KrasView для Android TV с управлением обычным пультом.
Текущая версия — **0.12**, пакет — `local.krasview.tv`.
Проект независимый и не является официальным приложением KrasView.

## Возможности

- Главная с популярными фильмами, сериалами и аниме.
- Поиск, системный голосовой ввод, раздел мультфильмов.
- Фильтр по типу, жанрам, году или десятилетию; переход по тегу жанра.
- Карточки без рейтингов и реакций: описание, просмотр и закладка.
- Выбор полного фильма, трейлера или другой версии с длительностью.
- Выбор сезонов и серий.
- Встроенный Media3-плеер: DASH/MP4, доступные разрешения и названия озвучек.
- Минимальный плеер без экранных кнопок; подсказка «↑ Настройки» рядом со временем.
- Субтитры SRT/ASS из KrasView: выбор дорожки и выключение в меню плеера.
- Перемотка по 10 секунд с ускорением при удержании, сохранение позиции.
- Локальные закладки и история, вход с телефона по коду.

## Управление пультом

| Кнопка | Действие в плеере |
| --- | --- |
| OK | Пауза / продолжить |
| Влево / вправо | Перемотка на 10 секунд |
| Удержание влево / вправо | Ускорение перемотки |
| Вверх, MENU или долгое OK | Озвучка, качество и субтитры |
| Вниз | Показать панель |
| Назад | Скрыть панель, затем вернуться к выбору видео |

В каталоге MENU открывает боковое меню. Влево от первой карточки — тоже меню,
вверх из первого ряда — поиск. Фильтр есть в меню и верхней панели.

## Сборка на Windows

Нужны **JDK 17**, **Python 3**, **PowerShell**, Android SDK Platform 34 и Build Tools 34.0.0.
Android Studio и Gradle не требуются: используется небольшой SDK-конвейер
`aapt2 → javac → d8 → zipalign → apksigner`.

1. Установите Android SDK и пакеты `platforms;android-34`, `build-tools;34.0.0`.
2. Задайте `JAVA_HOME` и `ANDROID_SDK_ROOT` либо передайте пути параметрами.
3. Выполните из папки проекта:

```powershell
python fetch_dependencies.py
./test.ps1
./build.ps1
python tests/audit_apk.py
```

Пример с явными путями:

```powershell
./build.ps1 -JavaHome 'C:/Tools/jdk-17' -AndroidSdkRoot 'C:/Android/Sdk'
```

Зависимости зафиксированы версиями и SHA-256 в `libs/media3-lock.json`.
Скрипт скачивает их из Google Maven/Maven Central и проверяет контрольные суммы.
Результат сборки — `KrasView-TV.apk`.

При отсутствии `krasview-tv.keystore` создаётся локальный ключ разработки.
Для подписания существующим ключом есть параметр `-SigningKey`; пароли можно
задать переменными `KRASVIEW_KEYSTORE_PASSWORD` и `KRASVIEW_KEY_PASSWORD`.
Для обновления уже установленной сборки нужен тот же ключ подписи.
Ключи и APK в репозиторий не входят.

## Проверки

`test.ps1` запускает автономные проверки перемотки, списка версий фильма,
изоляции галереи от рекомендаций и проверки длительности. Им не нужен телевизор
или аккаунт: HTML-фикстура синтетическая.

GitHub Actions собирает APK с временным ключом разработки и проверяет его состав.
Проверки на устройстве запускаются отдельно с явным ADB-адресом:

```powershell
python tests/device_tracks.py --serial 192.0.2.10:5555
python tests/device_catalog.py --serial 192.0.2.10:5555
python tests/device_movie_choices.py --serial 192.0.2.10:5555
python tests/device_mentalist.py --serial 192.0.2.10:5555
python tests/device_player_minimal.py --serial 192.0.2.10:5555
```

Адрес в примерах условный; замените его адресом своего устройства.
Эти тесты управляют приложением, включают видео и требуют действующего входа.
Для `device_player_minimal.py` нужен установленный DpadHold из `tests/android/`:
он проверяет удержание клавиши и не входит в APK.
Дополнительные детали — [в заметках разработки](docs/DEVELOPMENT.md).

## Текущее состояние

Проверено на Sharkstraid TV Stick со Slimbox AOSP 11: каталог, вход, управление
пультом, полный фильм и трейлер, DASH 360p/1080p, выбор озвучки и сохранение позиции.

- Источник сейчас один: KrasView. KinoPub и Filmix не подключены.
- Расписание пока показывает заглушку.
- Закладки и история не синхронизируются с аккаунтом сервиса.
- Полный вход через Google не подтверждён.
- API и разметка сервиса могут измениться; аккаунты, медиа и права доступа
  предоставляет сам сервис. Видеофайлы в репозитории отсутствуют.
- Рекламные SDK не включены. Вставки внутри самого видео отдельно не распознаются.

Сведения о сторонних библиотеках: [NOTICE](libs/NOTICE.txt) и
[полные уведомления](app/assets/third-party-notices.txt).
