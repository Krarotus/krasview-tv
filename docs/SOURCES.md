# Источники просмотра

Каталог пока предоставляет KrasView. Кнопка «Смотреть» предлагает выбор источника,
если настроен Lampac NG. Сам каталог, аккаунт KrasView и закладки при этом сохраняются.

## Lampac NG

Нужен работающий сервер [Lampac NG](https://github.com/lampac-nextgen/lampac).
Хранить фильмы на нём не требуется. На Windows для теста можно установить
ASP.NET Core Runtime 10, распаковать релиз, скопировать `example.init.yaml`
в `init.yaml` рядом с `Core.dll` и запустить `dotnet Core.dll`.
Полная [инструкция](https://docs.lampac.dev/deployment/windows).

1. Ноутбук и ТВ подключите к одной сети, разрешите серверу входящие подключения
   в частной сети Windows и оставьте ноутбук включённым.
2. Проверьте `http://localhost:9118/version?type=hash` на ноутбуке,
   затем `http://АДРЕС_НОУТБУКА:9118/version?type=hash` с другого устройства.
3. В приложении откройте «Источники» → «Настроить Lampac NG».
4. Укажите базовый адрес сервера, без `/online.js`. Токен вводится отдельно,
   только если он настроен на сервере. Нажмите «Проверить», затем «Сохранить».
5. В карточке фильма: «Смотреть» → «Lampac NG» → провайдер → вариант видео.

Пустой адрес отключает Lampac. Для внешнего сервера нужен HTTPS.
HTTP разрешён клиентским адаптером на localhost, частных IPv4 и доменах `.local`.
Android не поддерживает диапазоны частных IP в network security XML, поэтому
cleartext разрешён на уровне платформы, а адаптер проверяет допустимые адреса сам.
При смене IP ноутбука обновите адрес в настройках приложения.

## Возможности и ограничения

- `/lite/events` — список провайдеров; папки, озвучки, сезоны и серии отображаются
  нативными списками, удобными для пульта.
- Обрабатываются `data-json` с `method: link/call/play`, MP4, DASH и HLS.
  JavaScript провайдера и `online.js` не выполняются.
- Качество берётся из `quality`/`qualitys`; название озвучки — из `voice_name`,
  `translate` или выбранной папки озвучки. Источник может предоставить лишь один вариант.
- Для поиска передаются названия, год и тип. ID KrasView не выдаётся за ID TMDB.
  Сопоставление по названию может дать одноимённые фильмы: проверяйте выбор провайдера.
- Провайдеры с RCH/браузерным реле пока не поддерживаются. Доступность остальных
  зависит от сервера, региона, настроек и подписок соответствующих сервисов.
- Токен Lampac хранится отдельно от аккаунта KrasView, в приватном AES-GCM файле
  вне Android backup; ключ тоже находится в приватном каталоге приложения.
  Это защита от случайного раскрытия, не аппаратное хранилище.
- API-запросы с токеном ограничены адресом настроенного сервера. Произвольные
  заголовки не пересылаются: поддерживаются только Referer, Origin и User-Agent.
- Позиция видео Lampac сохраняется отдельно от позиции видео KrasView.
- Рекламные скрипты не запускаются. Вставки, встроенные в сам видеофайл или поток,
  отдельно не распознаются и не удаляются.

Проверено на реальном домашнем Lampac: список провайдеров, варианты озвучки
и полный «Ральф» через Filmix (480p, 1:41:13). Это не гарантия работы всех провайдеров.

## Добавление адаптера

`MediaSource` задаёт возможности, `browse(Query, reference)` и `resolve(Query, reference)`.
`CatalogSource` расширяет его операциями каталога. DTO находятся в `Media`.
Ссылки `reference` непрозрачны для интерфейса: их формат знает только адаптер.

Добавьте реализацию в `SourceRegistry`, собственную настройку подключения и проверки
контракта. UI браузера и плеер работают с общими моделями, а не с API провайдера.
Не помещайте серверные токены и адреса домашней сети в исходный код или фикстуры.

`test.ps1` проверяет парсер Lampac на синтетических данных, качества и озвучки,
ограничения адресов и утечку заголовков. Тестовый `org.json` используется только
на JVM, в APK применяется Android `org.json`. Jsoup входит в APK.
